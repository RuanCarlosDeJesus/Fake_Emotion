# 🌌 Fake Emotion

Fake Emotion é um projeto de interface para e-commerce fashion com identidade visual dark e estética cósmica. A aplicação simula uma loja de roupas premium inspirada em emoções intensas, arte visual neon e design contemporâneo.

## ✨ Conceito

A proposta do projeto é unir:
- Estética futurista / cyberpunk
- Glassmorphism e efeitos de blur
- Gradientes neon (rosa e roxo)
- Layout centralizado com painel translúcido
- Experiência visual imersiva

## 🚀 Tecnologias Utilizadas

- React
- TypeScript
- TailwindCSS
- Lucide Icons
- Vite

## 🎨 Funcionalidades

- Hero section com overlay e destaque visual
- Navbar responsiva com menu mobile
- Grid de produtos com efeito hover
- Cards com glow e bordas suaves
- Seção institucional ("Sobre nós")
- Layout responsivo (mobile-first)

## 📱 Responsividade

O projeto foi desenvolvido com abordagem mobile-first, garantindo:
- Menu lateral em dispositivos móveis
- Grid adaptável
- Tipografia escalável

## 📦 Objetivo

Este projeto foi criado para prática de:
- Composição visual moderna
- Design system com Tailwind
- Estruturação de componentes reutilizáveis
- Experiência UI premium
